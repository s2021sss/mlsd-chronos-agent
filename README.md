# Chronos Agent

Автономный помощник для планирования времени. Пользователь общается с ботом в Telegram
обычным текстом или голосом («перенеси созвон на завтра после обеда», «напомни про отчёт
за час»), а агент разбирает сообщение, ищет свободные окна и предлагает план изменений в
Google Calendar и Google Tasks. Изменения применяются только после подтверждения кнопкой;
напоминания бот присылает в Telegram.

**Цель:** упростить планирование повседневных дел, сократить время на организацию задач и
помочь эффективнее распределять время.

## Возможности (план)

- Диалог через Telegram-бот на естественном языке: текст и голосовые сообщения
- Разбор списка дел из одного сообщения на встречи, задачи и напоминания
- Управление Google Calendar: создание, перенос, отмена событий, поиск свободных слотов
- Задачи без конкретного времени - в Google Tasks
- Учёт часового пояса пользователя
- Напоминания и предложения по переносу при конфликтах в расписании
- Подтверждение пользователем перед любым изменением календаря; уточняющие вопросы, если данных не хватает

Подробности - в [дизайн-документе](docs/ml_system_design_doc.md).

## Стек (план)

Python 3.11+, aiogram 3, FastAPI, PostgreSQL, Docker Compose; LLM с tool calling
(Mistral Small / YandexGPT, локально Qwen для разработки); ASR - Whisper (`faster-whisper`);
Google Calendar API и Google Tasks API.

## Разработка

Нужны [uv](https://docs.astral.sh/uv/) и Python ≥ 3.11.

```bash
uv sync                          # окружение и dev-зависимости
uv run pre-commit install        # хуки на каждый коммит
uv run pre-commit run --all-files
uv run ruff check . && uv run ruff format --check .
```
